The Problem
Il Problema

Claude Code is powerful.
But it's missing key tools.

Claude Code è potente.
Ma gli mancano strumenti chiave.

If you use Claude Code in VS Code, you know the pain. VibeSync fixes it.

Se usi Claude Code in VS Code, conosci il problema. VibeSync lo risolve.

🔍
Can't search past chats
Non puoi cercare nelle chat passate
Claude Code saves conversations as .jsonl files with random names. Finding that chat from last week where you solved a bug? Good luck scrolling through quiet-nibbling-spring.jsonl.
Claude Code salva le conversazioni come file .jsonl con nomi casuali. Trovare la chat di settimana scorsa dove hai risolto quel bug? Buona fortuna a scorrere quiet-nibbling-spring.jsonl.
📁
No way to organize conversations
Nessun modo di organizzare le conversazioni
Unlike Claude Web, Claude Code has no projects, no folders, no tags. After a few weeks you have 50+ chats and zero structure.
A differenza di Claude Web, Claude Code non ha progetti, cartelle né tag. Dopo poche settimane hai 50+ chat e zero struttura.
💥
File conflicts in teams
Conflitti sui file nel team
Two developers (or two AI agents) editing the same file? No warning, no lock, just merge hell later. This is the #1 pain of vibe coding teams.
Due developer (o due agenti AI) che modificano lo stesso file? Nessun avviso, nessun lock, solo merge hell dopo. Il problema #1 dei team di vibe coding.

Tutto ciò che Claude Web offre per organizzare le chat — ora in VS Code. Cerca, rinomina, raggruppa in progetti, riprendi qualsiasi conversazione con un click.

Team Collaboration
Collaborazione Team

File Locking for AI Teams

File Locking per Team AI

Distributed lock system via GitHub API. When you (or your AI agent) edits a file, it gets locked. Others see who's working on what, in real-time.

Sistema di lock distribuito via GitHub API. Quando tu (o il tuo agente AI) modifichi un file, viene lockato. Gli altri vedono chi sta lavorando su cosa, in tempo reale.

🔒
Automatic Locks
Lock Automatici
FileSystemWatcher detects saves and auto-locks files. Claude Code hook integration locks files before AI edits them.
FileSystemWatcher rileva i salvataggi e locka automaticamente. L'integrazione con gli hook di Claude Code locka i file prima che l'AI li modifichi.
👀
Real-Time Sidebar
Sidebar in Tempo Reale
See your locks, other developers' locks, and the release queue — all in the VS Code sidebar. Polls GitHub every 30 seconds.
Vedi i tuoi lock, quelli degli altri developer e la coda rilascio — tutto nella sidebar di VS Code. Polling su GitHub ogni 30 secondi.
🔔
Conflict Warnings
Avvisi Conflitto
Get notified when someone starts or stops working on a file. Warning if you try to edit a file locked by another developer.
Ricevi notifiche quando qualcuno inizia o smette di lavorare su un file. Avviso se provi a modificare un file lockato da un altro developer.
⏰
Stale Lock Cleanup
Pulizia Lock Scaduti
Locks older than 24h are flagged as stale. Force-unlock them with one command. No abandoned locks polluting your workflow.
I lock più vecchi di 24h vengono segnalati come scaduti. Sbloccali con un comando. Nessun lock abbandonato a inquinare il workflow.

Quick Start
Guida Rapida

Up and running in 3 minutes

Operativo in 3 minuti

VibeSync needs Python, a GitHub repo, and VS Code. That's it.

VibeSync richiede Python, un repo GitHub e VS Code. Fine.

1

Create the config file

Crea il file di configurazione

Create ~/.vibesync/config.json with your settings:

Crea ~/.vibesync/config.json con le tue impostazioni:

{ "github_token": "ghp_your_token_here", "github_repo": "your-org/your-repo", "github_branch": "main", "github_lock_branch": "vibesync-locks", "developer_name": "YourName", "local_root": "/path/to/your/project", "github_desktop_root": "/path/to/git/repo", "excluded_dirs": ["node_modules", ".vscode"] }
2

Install the VS Code extension

Installa l'estensione VS Code

# From the Marketplace (coming soon) code --install-extension aresbi.vibesync # Or from .vsix file code --install-extension vibesync-1.0.0.vsix --force
3

Start using it

Inizia a usarlo

  • Click the lock icon in the VS Code sidebar to open VibeSync
  • Use Search Chats to find and resume any past conversation
  • Use Chat Projects to organize your sessions into folders
  • Use Sync Dashboard to push files to your Git repo
  • File locks happen automatically when you save
  • Clicca l'icona lucchetto nella sidebar di VS Code per aprire VibeSync
  • Usa Cerca nelle Chat per trovare e riprendere qualsiasi conversazione
  • Usa Progetti Chat per organizzare le sessioni in cartelle
  • Usa Sync Dashboard per sincronizzare i file nel repo Git
  • I lock sui file avvengono automaticamente quando salvi
